# mailctl brand assets

Use the mole with the project name for README headers and the standalone mole
with its envelope for icons.

| Asset | Colour | Dark background | Black | White |
| --- | --- | --- | --- | --- |
| Mole and name | [SVG](mailctl-readme.svg) | [SVG](mailctl-readme-dark.svg) | [SVG](mailctl-readme-black.svg) | [SVG](mailctl-readme-white.svg) |
| Mole and envelope | [SVG](mailctl-mascot.svg) | [SVG](mailctl-mascot-dark.svg) | [SVG](mailctl-mascot-black.svg) | [SVG](mailctl-mascot-white.svg) |

The colour versions keep charcoal fur, cream paper and a terracotta nose across
backgrounds. The dark versions add a thin warm outline and cream facial details.
Use the black or white versions for a single-colour mark.

The name uses IBM Plex Mono SemiBold, converted to vector outlines. All artwork
and lettering are editable SVG paths; no installed fonts or embedded images are
required.

The source font is [IBM Plex Mono SemiBold from Google Fonts](https://github.com/google/fonts/blob/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/ibmplexmono/IBMPlexMono-SemiBold.ttf),
