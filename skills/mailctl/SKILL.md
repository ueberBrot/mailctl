# mailctl

For installation, component updates, or account setup, read [Installation and setup](references/installation.md).
That reference also covers credential provisioning in the operator's terminal.
Installing components does not authorize account changes or email access.

For email discovery, search, message and attachment reads, or unsent drafts, read [CLI and MCP usage](references/usage.md).
Use the installed guides and schemas for version-specific inputs.
The usage reference covers result boundaries and links to draft recovery when needed.

If a request covers setup and email work, finish the requested setup before using the email interface.
Keep each action within the user's authorization and the operator's access grant.
